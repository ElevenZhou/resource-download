# Playbox 探查笔记（免登录）

> 日期：2026-08-08  
> 方式：分析前端 `main.*.js` + 直打 `api.playbox.com`  
> 结论：**清单页（Explore）免登录即可拿到人物图、封面、视频 URL + 作品名 + 发布者；标签在列表里已有，详情可再取一遍。**

## 1. 站点形态

| 项 | 值 |
|----|-----|
| 前端 | SPA（`www.playbox.com`，React 打包） |
| API | `https://api.playbox.com` |
| 媒体 CDN | `playbox-storage.b-cdn.net` / `playbox-videos.b-cdn.net` / `playbox-uploads.b-cdn.net` 等 |
| 鉴权 | 写操作需 Bearer；**Explore / Feed 公开 GET 可匿名** |

前端 axios：

- `Ay` → `https://api.playbox.com/api`（部分接口带登录 token）
- 公开 Explore 实测 **不带 token 也 200**

## 2. 清单页 API（核心）

```http
GET https://api.playbox.com/api/model/explore/?page=1
Accept: application/json
Origin: https://www.playbox.com
Referer: https://www.playbox.com/explore/
```

可选查询：`search`、`keyword`；路径还可带 category：`/api/model/explore/{categoryId}?page=`

响应摘要：

```json
{
  "message": "Explore collections found",
  "data": [ /* 每页约 30 条 collection */ ]
}
```

### 字段映射（与你说的一致）

| 你要的 | JSON 路径 | 说明 |
|--------|-----------|------|
| **作品名** | `name` | 如模板/作品标题 |
| **发布者** | `username` | 另有 `user`（用户 id） |
| **人物图** | `input.image.url` | 图生视频的输入人像/素材图；可有 `resizedImage` |
| **封面图** | `output.video.posterUrl` | 视频封面/poster |
| **视频** | `output.video.url` | 亦可 `compressedUrl`（常同链或压缩版） |
| **标签** | `tags[].name` | 列表里已有；详情同样返回 |
| 补充 | `keywords[]` | 内容关键词（比 tags 更细的一组） |
| 补充 | `categories[]` | 分区名，如 Trending / VIP Creators |

条目 id：`_id`（collection id）  
详情页前端路由形态：`/collection/...` 或 API：`GET /api/model/{_id}`

### 抽样完整度（page=1，30 条）

- 人物图 + 封面 + 视频 + 名 + 作者 齐全：**27/30**
- 缺视频/封面的多为 **Picture / Edit Image** 类（`modelType` 偏出图，不是视频）

媒体 HEAD 抽检（带 Referer）均为 200，可直链下载：

| 资源 | Content-Type | 约大小（样例） |
|------|--------------|----------------|
| 人物图 | image/webp | ~30KB |
| 封面 | image/png | ~39KB |
| 视频 | video/mp4 | ~500KB+（样例；真实更长会更大） |

URL 带 `token` + `expires` 签名 → **入库应存 `_id`，下载前可重新 explore/detail 刷新链接。**

## 3. 点击详情

```http
GET https://api.playbox.com/api/model/{collectionId}
```

- `message`: `Collection found`
- `tags` / `keywords` / `categories` 与列表一致或更完整
- 另有 `related`、`rating` 等列表可能没有的字段

标签示例（列表已返回，不必非点详情）：

```json
"tags": [{"name": "4K", "tagId": "..."}, {"name": "VIP", "tagId": "..."}]
"keywords": ["POV", "Couple", ...]
```

## 4. 旁路：Feed（Reels 流）

```http
GET https://api.playbox.com/api/feed?limit=20
GET https://api.playbox.com/api/feed/ranked?limit=20
```

也有 `name` / `username` / `input.image` / `output.video`，但 **tags 常为空**；Explore 更适合「作品清单 + 标签」。

## 5. 抓取实现要点（下一步代码）

```text
for page in 1..N:
  GET /api/model/explore/?page={page}
  for item in data:
    record = {
      id: item._id,
      name: item.name,
      username: item.username,
      character_image: item.input.image.url,
      cover: item.output.video.posterUrl,
      video: item.output.video.url or compressedUrl,
      tags: [t.name for t in item.tags],
      keywords: item.keywords,
    }
    # 无 video 且 modelType 为出图 → 可只下人物图或标 skip_video
```

下载服务：对三个 URL 做 HTTP 并发即可（非 m3u8）；失败则 `GET /api/model/{id}` 刷新后再试。

## 6. 弹层 Modal vs 列表（2026-08-08）

点击卡片 → `GET /api/model/{id}`，前端 `selectedCollection` / CollectionModal。

| 区块 | 内容 |
|------|------|
| root | 当前作品三件套 |
| **`extend[]`** | 弹层内横向/网格画廊；每项是**完整 generation**（自有 `_id`、人物图、封面、视频），样例一条可有 **40～50** 组 |
| `related[]` | 相关推荐，结构类似 |

用户看到「好多人物图」→ 主要来自 **`extend` 多组样例**，不是单条 `input.image2`。

`pbdl resolve` 默认展开 `extend`；`crawl --with-extend` 对每张卡片打详情。

## 7. 单条多输入图

| 事实 | 说明 |
|------|------|
| 生成时可传 | `image` / `image2` / `imageUrl2`… |
| 公开回读 | 多数仍只有 1 个 `input.image` |
| resizedImage | 同图缩略；原图 403 时可 fallback |

## 7. 合规

- 仅处理站点 **公开 isPublic** 资源；匿名 Explore 已暴露的链接。
- 不登录破解 VIP 生成、不绕过付费。
- 内容属成人 AI 生成站，注意本地法律与 ToS，**仅自用归档**。
- 控制 `page` / 并发，避免压垮 API/CDN。
